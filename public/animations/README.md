# Hero animation sources

User-supplied Lottie JSON files, hosted locally with their embedded image assets.

- burger.json: Bouncing Burger by Bilal / Bilal Naseer — https://lottiefiles.com/free-animation/bouncing-burger-0UEkWhq5Gb
- pizza.json: Pizza Slices by Tomer Arnon — https://lottiefiles.com/free-animation/pizza-slices-pLMsRcTEhI

Both source listings identify the Lottie Simple License. Preserve these credits and the source license when redistributing the assets.

The hero scrubs burger frames 12–116 and pizza frames 18–76. It intentionally excludes the pizza's later dispersal, then adds CSS rotation. Scroll playback stays enabled even when the OS requests reduced motion, per the site owner’s preference. The visible Pause animation control displays assembled frames. Phone scrubbing uses longer scroll travel and frame-rate-independent smoothing. The animation player is imported on the client; API/order behavior is unchanged.
